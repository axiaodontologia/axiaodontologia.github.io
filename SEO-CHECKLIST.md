# SEO Checklist — Axia Odontología

Marca cada casilla contra el sitio en producción, no contra la maqueta.

## En la maqueta entregada (hecho)
- [x] Un solo H1 por página, con ciudad en las páginas de servicio
- [x] Title y meta description únicos por ruta
- [x] Canonical por ruta apuntando a https://www.axiaodontologia.com + path
- [x] Open Graph y Twitter Cards por ruta
- [x] JSON-LD: Dentist, WebSite, BreadcrumbList, Service, Article, FAQPage
- [x] Breadcrumbs visibles en servicios y blog
- [x] Enlazado interno servicio ↔ servicio y artículo → servicio
- [x] HTML semántico (header/nav/main/section/article/footer)
- [x] Alt descriptivo en cada imagen, con el nombre de archivo SEO indicado
- [x] robots.txt y sitemap.xml con las 18 rutas
- [x] 404 útil con salidas a inicio, servicios y WhatsApp
- [x] Enlaces del footer corregidos: ya no apuntan a oralty.com.co
- [x] prefers-reduced-motion respetado
- [x] Foco visible en todos los elementos interactivos

## Pendiente en producción (requiere dominio, hosting o datos reales)
- [ ] Redirección 301 de axiaodontologia.com → www.axiaodontologia.com (o al contrario), una sola versión
- [ ] HTTPS forzado y HSTS
- [ ] Redirecciones 301 de las URLs viejas de Wix a las nuevas (tabla en README)
- [ ] Publicar dirección exacta, horarios y teléfono fijo → completar `SITE` en site-data
- [ ] Sustituir cada image-slot por la foto real en WebP con srcset
- [ ] Core Web Vitals: LCP < 2.5 s, INP < 200 ms, CLS < 0.1 (medir en PageSpeed con URL real)
- [ ] Verificar propiedad en Google Search Console y enviar sitemap
- [ ] Perfil de Google Business con el mismo NAP que el footer
- [ ] GA4 con los eventos de conversión marcados como conversión
- [ ] Comprobar indexación de las 7 páginas de servicio a los 15 días
- [ ] Revisar enlaces rotos con Screaming Frog antes de lanzar

## Datos que NO se han inventado y siguen faltando
Dirección · horarios · teléfono fijo · nombres y especialidades del equipo · fotos de la clínica · fotos de casos con autorización firmada · reseñas · años de experiencia.
